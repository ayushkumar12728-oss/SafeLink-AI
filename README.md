# 🛡️ SafeLink AI

> **AI-Powered Cyber Threat Detection & Cyber Awareness Platform**

SafeLink AI is an intelligent cybersecurity platform designed to protect users from phishing attacks, malicious websites, fake QR codes, and online scams. By combining AI-driven analysis with real-time threat intelligence and an interactive Cyber Academy, SafeLink AI empowers users to browse the internet more safely and confidently.

---

## 🚀 Features

### 🔍 AI URL Scanner
- Detects phishing and malicious websites
- AI-powered threat explanation
- Domain reputation analysis
- SSL certificate validation
- WHOIS lookup
- DNS analysis
- HTTP security inspection
- VirusTotal integration
- URLScan integration
- Intelligent risk scoring

### 🎓 Cyber Academy
- Interactive cybersecurity learning modules
- Topic-wise structured courses
- Quizzes and assessments
- Progress tracking
- Achievement badges
- Downloadable completion certificates
- Daily cybersecurity tips
- Scam awareness content
- Government cyber safety resources

### 📱 QR Guardian
- Scan suspicious QR codes
- Detect malicious QR redirects
- Preview destination URLs
- AI-powered QR risk analysis

### 🚨 Threat Feed
- Latest phishing campaigns
- Scam awareness
- Threat categories
- Warning indicators
- Security recommendations

### 📊 Security Dashboard
- Risk visualization
- Threat score
- AI-generated security summary
- Scan history (extendable)

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/ayushkumar12728-oss/SafeLink-AI.git
```

```
cd SafeLink-AI
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

uvicorn main:app --reload
```

---

# 🌐 Environment Variables

Create a `.env` file inside the backend directory.

```env
VT_API_KEY=YOUR_VIRUSTOTAL_API_KEY
URLSCAN_API_KEY=YOUR_URLSCAN_API_KEY
```
